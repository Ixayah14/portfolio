An immersive, high-performance personal web developer portfolio inspired by traditional Japanese samurai aesthetics (**Bushido & Sumi-e** ink wash) blended with modern digital craftsmanship.

---

## ⚔️ Key Experience & Features

- **🌊 Navier-Stokes Fluid Canvas**: Real-time GPU fluid dynamics simulation (`dye-whorl.js`) producing living sumi-e ink smoke and dye plumes reactive to cursor velocity and screen taps.
- **⚡ Iaido Katana Cleave Intro**: Upon reaching 100% load, the preloader snaps its visual buffer, unleashes a crimson Katana slash beam with screen recoil, and physically cleaves the intro into two diagonal sliding halves.
- **🗡️ Interactive Katana Sheath Scroll Rail**:
  - Replaces traditional browser scrollbars with a custom SVG Katana scabbard.
  - Dynamically unsheathes the blade as you read down the page.
  - **Drag-to-Scroll**: Click and drag the scabbard up and down to scrub the page in real-time.
  - Real-time **Battou Depth (0%–100%)** HUD and strike slash flourish.
- **🛡️ Core Technology Matrix (Bento Arsenal)**:
  - Interactive weapon tiles covering frontend, backend, styling, and graphics disciplines.
  - Live **Forge Inspector** displaying detailed capability manifests, code-level standards, and execution logs on hover.
  - Authentic builder grading (Proficient / Intermediate / Foundational).
- **📱 Touch & Mobile Optimized**: Zero horizontal overflow, touch-first gesture tracking, responsive navigation drawer, and cross-browser resilience.

## 🚀 Getting Started

To run this portfolio locally:

1. **Clone the repository**:
   ```bash
   git clone https://github.com/Ixayah14/portfolio.git
   cd portfolio
   ```

2. **Open in browser**:
   Simply open `index.html` in any modern web browser, or serve it using a lightweight local development server:
   ```bash
   npx serve .
   # or
   python -m http.server 3000
   ```

3. Open `http://localhost:3000` to experience the portfolio.
